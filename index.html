工作流

  1. 1. 网页批量上传 —— 用户在前端提交图片、链接或表格。
  2. 2. 任务进入队列 —— 同一会话内串行调度，避免 Temu App 状态互相干扰。
  3. 3. 云端 Temu App 执行 —— VMOS 内 Temu Android App 作为会话执行端，触发图搜。
  4. 4. 响应离线解析 —— 从原生 TLS 明文 → HTTP/2 重组 → gzip 解压 → 字段抽取。
  5. 5. 结果入库与展示 —— 写入 JSON / CSV；前端轮询 / 导出。

常见问题

是否需要账号？

不需要。云端 Temu App 已登录，开机即用。

单张 / 批量的限制？

单张无限制；批量建议 ≤ 200 张，避免云手机内存吃紧。

图搜接口会变吗？

会。每次接口版本调整都可能影响返回字段；系统做了响应结构自适应与字段缺失告警。

数据会公开吗？

不会。所有结果仅保存在本仓库 results/ 目录，不上传第三方服务。
